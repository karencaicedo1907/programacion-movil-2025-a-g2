# Retroalimentación del Examen Teórico

## Resumen
Durante esta semana, se llevó a cabo un examen teórico con el objetivo de evaluar la comprensión de conceptos clave en diversas áreas del desarrollo de software. La evaluación abarcó temas esenciales como control de versiones, metodologías ágiles, contenedores Docker y desarrollo de aplicaciones móviles. A continuación, se presentan los aspectos más relevantes de cada tema, junto con explicaciones que refuerzan su comprensión.

## Temas Evaluados

### Control de Versiones con Git
Se abordaron conceptos fundamentales sobre Git, destacando el uso del comando `git push origin <nombre_rama>` para enviar cambios desde una rama local a un repositorio remoto. También se analizó el estándar de Conventional Commits, que facilita la legibilidad del historial del proyecto y mejora la automatización en procesos de desarrollo.

### Metodologías Ágiles
En este apartado, se revisó el concepto de Historia de Usuario (HU) y su importancia en el desarrollo ágil. Se enfatizó que una HU debe estar estructurada con tres elementos esenciales: el usuario o rol, la acción o funcionalidad requerida y el valor esperado. Además, se destacó la relevancia de estos elementos para guiar la implementación de software alineada con las necesidades del usuario final.

### Contenedores y Docker
Se evaluaron aspectos clave de Docker, incluyendo la utilidad del comando `docker-compose up -d --build`, el cual permite reconstruir las imágenes y ejecutar contenedores en segundo plano. Se explicó que Docker facilita la creación y distribución de aplicaciones en entornos aislados y portátiles, lo que mejora la consistencia entre los entornos de desarrollo y producción.

### Desarrollo de Aplicaciones Móviles
El examen también incluyó preguntas sobre herramientas y lenguajes utilizados en el desarrollo de aplicaciones móviles. Se identificó a Android Studio como el IDE oficial para la creación de aplicaciones en Android y a Xcode como el entorno de desarrollo principal para iOS y macOS. Además, se resaltó la importancia de Kotlin como el lenguaje recomendado para Android y Swift para iOS, debido a sus ventajas en seguridad y eficiencia.

## Conclusiones
Este examen permitió evaluar y reforzar conocimientos fundamentales en el ámbito del desarrollo de software. La revisión de estos temas no solo contribuye al entendimiento teórico, sino que también facilita su aplicación en escenarios prácticos. Comprender estos conceptos es esencial para mejorar la eficiencia en el desarrollo de proyectos y fortalecer habilidades clave dentro del sector tecnológico.
